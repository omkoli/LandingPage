- (decision) Access model = OPEN bug-bounty (unlimited hunters can pick any live program). DIVERGES from forge report-pack model; founder pays per validated finding. Implies dedup + spam control are load-bearing.
- (decision) Severity = CVSS-style scored rubric (tester proposes score, mediator confirms), mapped to payout band. DIVERGES from forge fixed-tier mechanical model. Borrows CVSS structure, not security scope.
- (decision) Roles = 4 first-class actors: Tester, Founder/Company, Mediator/Triager, Platform Admin.
- (decision) V1 scope = FULL marketplace MVP (launch-grade): both signups, program hosting+guidelines, browse/hunt, finding submission, CVSS scoring, mediation, payouts, testivity feed, hall-of-fame.
- (decision) Stakes = real launch. Full rigor: NFRs, success metrics + counter-metrics, dispute/payment/trust concerns all in scope.
- (decision) Working mode = Coaching path, Features-first entry. Walk capability-by-capability; section order = capability-driven.
- (decision) Onboarding: Tester = application + manual admin approval (quality-gated supply). Founder = company account -> many programs (multi-MVP/reruns). Payment setup = deferred until money moves (payout at first bounty, founder pays at first funding).
- (assumption) TENSION noted: open-bounty (max supply) + manual tester approval (throttled supply) coexist -> admin approval queue is a throughput dependency. Coherent as 'quality-gated supply, open competition among approved'.
- (decision) Testivity feed = REDACTED PUBLIC: public sees finding count + severity distribution + tester credits, details hidden. Trust signal without IP leak.
- (decision) Recognition = BOTH per-program hall-of-fame/thanks (def #2) AND global leaderboard. Opt-in anonymity per tester.
- (decision) Program lifecycle = bounty budget cap + auto-pause when budget exhausted; founder can top up. This is the open-bounty founder-spend-control mechanism.
- (decision) Guidelines Wizard = keep forge 7-step as-is (basics/core-actions/aha/claims/out-of-scope/test-access/review+publish + auto-extract + testability score + versioned snapshots). NDA/IP handling moves to Capability 8, NOT inline wizard step 8.
- (decision) Hunting = TRACKED 'Start Hunt' session tied to guidelines version; founder sees active-hunter count. Concurrency cap ~3 active hunts/tester (admin-configurable). Access = always immediate, self-serve methods only (magic-link/shared-creds/public-signup). Session tracking = screen-record attach (buy not build), no custom extension v1.
- (change) Wizard Step 6 loses 'founder-per-tester provisioning' option in v1 (access must be self-serve/immediate). Only 3 access methods remain. Reconcile against guidelines-wizard-v0.md at finalize.
- (decision) CVSS-style rubric = 4 dimensions (Impact, Scope, Reproducibility, User-Blocking), each 0-3, composite 0-12 normalized/banded. Tester proposes score at submission; mediator confirms/overrides; mediator score is binding + pays. Founder may dispute.
- (decision) Score->payout = FIXED BANDS (keeps forge tier $ amounts: Trivial $0/Minor $3/Major $10/Critical $25, +Severe $50 top band). Finding CATEGORIES A-E coexist orthogonally: category drives citation rules (A/D no citation; B/C/E require guideline citation), score drives payout.
- (decision) Mediation: shared triage QUEUE, mediators pull next (conflict-of-interest guard: cannot mediate own/related hunts). Two dispute axes: validity + severity score. Escalation = 2 levels (mediator -> 2nd mediator FINAL, no admin appeal). SLAs = both triage SLA (protect overnight wedge) + founder-ghost auto-resolve (>96h -> default rules); both admin-configurable.
- (decision) Founder proactive actions on a finding: acknowledge/mark-fixed (feeds fix-rate), award discretionary bonus/thanks (feeds hall-of-fame), comment/request-clarification via mediator. Plus dispute. NOT dispute-only.
- (change) MONEY MODEL CHANGED from forge. BetaCheck revenue = FLAT HOSTING FEE per program (founder pays to list). Bounty budget funded SEPARATELY by founder, 100% pass-through to testers (NO platform cut on bounties; tester gets full band amount). Supersedes forge's '25% of bonuses + flat base fee'.
- (decision) Base pay = HYBRID: first N quality reports per program earn small base ($8), founder-funded; beyond N -> bounty-only. Dedup = first valid submitter paid full, later duplicates $0. Payout rail v1 = UPI (India instant), single rail. Founder billed USD, tester paid INR.
